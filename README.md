# Deriv Digit Analyzer

This repository contains the browser dashboard, PWA files, setup notes, and a Deriv Bot starter XML.

Important:
- Public tick analysis does not require a Deriv password.
- The dashboard's percentages are historical statistics, not guarantees.
- The current analyzer login is a development UI shell; production authentication requires a hosted HTTPS backend/auth provider.
- The Android app shell and secure production authentication are separate deployment steps.
- Demo testing is recommended before any real-money execution.
